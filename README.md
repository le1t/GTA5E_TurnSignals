# GTA5E_TurnSignals
Включает управление поворотниками и аварийной сигнализацией в автомобилях GTA 5 Enhanced. Скрипт сам синхронизирует поворотники машины и выводит на экран аккуратные анимированные желтые стрелочки. Главная фишка — умное автоотключение: сигнал сам гаснет после завершения маневра, когда руль возвращается в прямое положение.

Клавиша 1 — левый поворотник (вкл/выкл).

Клавиша 2 — правый поворотник (вкл/выкл).

Клавиша 3 — аварийка (вкл/выкл, отключает поворотники).

Установка:

Скопируйте GTA5E_TurnSignals.cs в папку scripts

Требования:

1. Script Hook V https://www.dev-c.com/gtav/scripthookv/
2. ScriptHookVDotNetEnhanced 3.9.0.6 (1.1.0.6) https://github.com/Chiheb-Bacha/scripthookvdotnetenhanced
